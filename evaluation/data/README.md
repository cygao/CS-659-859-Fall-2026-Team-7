# Evaluation Data

Keep data used by the experiment in this folder. The approved proposal calls for 10 synthetic resumes and 5 real entry-level software job postings. It then forms 50 resume and job pairs.

Separate prompt-development examples from verification examples. Record each data source and dataset version. Use synthetic resumes only. Follow course rules for job posting text. Do not put real applicant data or secrets here.

Do not tune prompts on the verification set. Do not add results or claim a method until the team records it in `docs/evaluation-plan.md`.

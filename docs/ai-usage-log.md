# AI Use Log

Use this log to record how the team uses coding and language model tools. Keep entries factual. Do not include private resume text, job descriptions, or credentials.

## Entry template

Copy this block for each meaningful use:

```text
Date:
Owner:
Tool and model:
Task:
Files or prompts affected:
What the tool produced:
What the owner reviewed or changed:
How the owner checked the result:
Known limits:
```

Each feature owner remains responsible for generated code and content. Record material errors and their correction. Do not treat a successful tool response as proof that the app works.

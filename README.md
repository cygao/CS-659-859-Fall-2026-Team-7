# CS-659-859-Fall-2026-Team-7

This repository contains the team's local job application and resume project.

## Project status

The product requirements are in [project.md](project.md). The app framework is still open. This repository has shared data contracts, a SQLite schema, JSON interchange, and agent guidance. It has no app interface or runnable app yet.

## Repository map

- `docs/` explains the data model, architecture, platform decision, evaluation plan, and AI use log.
- `schemas/` defines the JSON interchange format.
- `migrations/` contains ordered SQLite schema changes.
- `examples/` contains synthetic sample data.
- `app/` is reserved for the app shell and feature screens after the platform and visual direction are approved.
- `evaluation/` separates data, scripts, and results from app data.

## Start here

1. Read [project.md](project.md) and [AGENTS.md](AGENTS.md).
2. Review [the shared application model](docs/application-model.md).
3. Review [the platform decision](docs/decisions/ADR-0001-platform.md) with the team.
4. Keep sample and demo data synthetic.

No build command is available yet because the app framework is not selected. Record the selected framework and build steps here after the team completes the platform spike.
